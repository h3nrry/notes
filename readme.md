# Personal Notes

This is my personal notes repository — organized by topic, one folder per subject.

## Contents

- [HDL](hdl/readme.md) — hardware description languages (Verilog, SystemVerilog, and future additions like VHDL)

## Structure

Each topic folder follows the same pattern:

- `readme.md` — overview / index for the topic, links to sub-topics
- sub-folders for each language or area, each with its own `readme.md`
- a `detail/` folder holding deep-dive notes on specific concepts (one concept per file)

New topics get added the same way: a new top-level folder with its own `readme.md`, linked from here.
